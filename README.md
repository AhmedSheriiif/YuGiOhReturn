# YuGiOh Return

A Yu-Gi-Oh! duel game for Windows PC with the look and sound of *Yu-Gi-Oh! Power of Chaos: Joey The Passion*.
Duel Joey as the computer opponent, or play your friends over LAN / Radmin VPN.

## Download and play

1. Go to **[Releases](https://github.com/AhmedSheriiif/YuGiOhReturn/releases/latest)** and download `YuGiOhReturn-<version>-full.zip`.
2. Unzip it anywhere (for example your Desktop).
3. Open the `YuGiOhReturn` folder and double-click **YuGiOhReturn.exe**.

The game checks for updates when it starts and installs them for you.
